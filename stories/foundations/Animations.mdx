## Staggered entrance

Pattern from `DESIGN_REFERENCE.md:148`:

```tsx
delay={i * 80}
style={{ transitionDelay: `${delay}ms` }}
```

For performance: animate only `transform` + `opacity` (GPU-accelerated), avoid `width/height`. Use `will-change` sparingly. Respect `prefers-reduced-motion` (`app/globals.css:199` disables animations).

```css
@media (prefers-reduced-motion: reduce) {
  .animate-fade-in-up,
  .animate-fade-in,
  .skeleton {
    animation: none !important;
  }
}
```
