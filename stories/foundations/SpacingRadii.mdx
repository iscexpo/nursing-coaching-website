# Spacing & Radii

Source: `app/globals.css:55` (`--radius`) and `DESIGN_REFERENCE.md:36`/`192`.

## Radius scale

`--radius: 0.5rem` (`app/globals.css:66`). Derived via `@theme inline`:

| Token        | Calc   | px     | Usage                    |
| ------------ | ------ | ------ | ------------------------ |
| `radius-sm`  | `*0.6` | 4.8px  | inputs small             |
| `radius-md`  | `*0.8` | 6.4px  | buttons                  |
| `radius-lg`  | `*1.0` | 8px    | `rounded-lg`             |
| `radius-xl`  | `*1.4` | 11.2px | `rounded-xl`             |
| `radius-2xl` | `*1.8` | 14.4px | `rounded-2xl` main cards |
| `radius-3xl` | `*2.2` | 17.6px | large sections           |
| `radius-4xl` | `*2.6` | 20.8px | hero                     |

Per `DESIGN_REFERENCE.md:38`: small `rounded-xl` (12px), primary `rounded-2xl` (16px aesthetic, maps to `radius-2xl` token).

## Spacing scale

| Name | px   | Class           |
| ---- | ---- | --------------- |
| xs   | 2px  | `p-0.5`         |
| sm   | 4px  | `gap-1`         |
| md   | 8px  | `gap-2`         |
| lg   | 16px | `gap-4` / `p-4` |

| 2xl  | 32px | `gap-8`         |
