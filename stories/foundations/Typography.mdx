## Font families

| Token   | Variable         | Stack                                                                |
| ------- | ---------------- | -------------------------------------------------------------------- |
| sans    | `--font-sans`    | `var(--font-hind), 'Hind Siliguri', ui-sans-serif, system-ui`        |
| heading | `--font-heading` | `var(--font-inter), var(--font-hind), 'Inter', 'Hind Siliguri', ...` |
| display | `--font-display` | `var(--font-inter), var(--font-hind), 'Inter', ...`                  |

`app/globals.css:293` applies `font-family: var(--font-hind)` globally; `body` uses `bg-background text-foreground`.
