## Usage guidance

- **Consistency:** Use `StatusBadge` icons via `statusConfig` (`components/ui/status-badge.tsx:35`) — don't invent ad-hoc.
- **Color:** Inherit `text-*`; for status use `bg-*/10 text-*` patterns (e.g. `bg-green/10 text-green` in `InvoiceStatusBadge`).
- **Accessibility:** Add `aria-hidden="true"` for decorative icons; provide text label alongside (`components/ui/status-badge.tsx:133` uses label + icon).
- **Performance:** `lucide-react` is tree-shaken; import individual icons: `import { Check } from 'lucide-react'`.

```tsx
import { CheckCircle2, XCircle, AlertCircle } from 'lucide-react'
<span className="inline-flex items-center gap-1 rounded-full bg-green/10 text-green px-2 py-0.5 text-xs">
  <CheckCircle2 className="size-3" /> Present
</span>
```

See `components/ui/status-badge.tsx:148` for `AttendanceStatusBadge` icon mapping and `lib/payment/index.ts` for method colors.
