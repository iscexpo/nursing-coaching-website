# Shadows & Glass

Spec: `DESIGN_REFERENCE.md:4` (Glassmorphism) and `DESIGN_REFERENCE.md:22` (Soft Shadows).

## Glassmorphism

Template from `DESIGN_REFERENCE.md:84`:

```tsx
className="rounded-2xl border border-white/20 dark:border-white/10
           bg-white/40 dark:bg-slate-900/40 backdrop-blur-xl
           transition-all duration-300
           hover:border-white/40 dark:hover:border-white/20
           hover:bg-white/60 dark:hover:bg-slate-900/60
           hover:shadow-xl hover:shadow-blue-500/10"
```

Uses in codebase: hero floating cards, `components/sections/why-us.tsx`, `courses.tsx`, counters.

Tokens:

- Light: `rgba(255,255,255,0.4)` bg, `rgba(255,255,255,0.2)` border
- Dark: `bg-slate-900/40`, `border-white/10`, more opaque `bg-slate-900/50` for readability (`DESIGN_REFERENCE.md:182`)

Fallback without `backdrop-blur`: solid `border + opacity` for Safari &lt;15.1.

## Soft shadows

Guidance from `DESIGN_REFERENCE.md:22`:

- Hover: `shadow-xl hover:shadow-2xl`
- Colored: `hover:shadow-blue-500/10` or `hover:shadow-blue-500/30` (primary CTA)
- Never pure black — use colored shadows

```tsx
  'border-2 border-blue-200 dark:border-blue-800 text-blue-600 dark:text-blue-400 hover:bg-blue-50/40'
```
